# Emergency Fund Target Months Calculator

A financial planning tool that calculates your personalized emergency fund target based on monthly fixed expenses, variable expenses, and an income stability factor ranging from 3 to 12 months. Enter your current savings and monthly contribution amount to see a progress bar toward your goal and an estimated time to completion.

## Features

- Separate inputs for fixed and variable monthly expenses
- Income stability selector (Very Stable to Highly Variable) maps to 3–12 month recommendations
- Auto-calculates total monthly expenses and target fund amount
- Progress bar showing current savings vs. target
- Time-to-goal estimate based on monthly contribution rate
- Save and restore all inputs via localStorage
- Clear labeling with hint text on each input field
- Accessible: labeled inputs, ARIA progressbar role with dynamic valuenow
